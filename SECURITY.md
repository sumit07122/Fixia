## Reporting a Vulnerability

The FIXIA team takes the security of our public systems and user data seriously. If you discover a security vulnerability or potential credential exposure:

1. **Do not create a public GitHub issue.** Public disclosure can place live infrastructure and client privacy at risk.
2. Submit your report through **GitHub Private Vulnerability Reporting** via the repository's **Security** tab (`https://github.com/sumit07122/Fixia/security/advisories/new`).
3. If private vulnerability reporting is unavailable, open a confidential issue requesting direct maintainer contact without disclosing the vulnerability payload.

### Report Details
Please include:
- Description of the vulnerability and attack vector.
- Affected URL, script, or endpoint.
- Step-by-step reproduction instructions or Proof of Concept (PoC).
- Expected vs observed security behavior.

The maintainers will review the submission, reproduce the findings, and apply appropriate remediation in a timely manner.
